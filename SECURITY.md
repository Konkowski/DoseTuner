# Security

DoseTuner runs fully client-side: no server, no accounts, no network calls with your data. Files you load stay on your device (IndexedDB in your browser).

**Report a vulnerability** privately through GitHub: *Security → Report a vulnerability* on this repository. Please do not open a public issue for security problems. You will get an answer as soon as possible.

**Operational note:** DoseTuner only proposes values. Never connect it to a machine in a way that lets it write setpoints without a human check.
